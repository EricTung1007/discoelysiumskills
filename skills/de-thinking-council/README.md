# Thinking Council

An independent, non-coding adaptation of the 24 Disco Elysium voices. Start with [SKILL.md](SKILL.md). The original coding skills remain unchanged in `skills/de-*`.

## Use
Ask: 「請用 Thinking Council 幫我分析這個情況……」 or “Discuss this with Logic, Empathy and Half Light.” For all perspectives ask 「召開完整 24 聲音會議」.

## Principles
Evidence first; no deliberate errors, invented disagreements or fake mind-reading. Voices are analytical lenses; the user makes the decision. See individual voice files under `voices/`.
